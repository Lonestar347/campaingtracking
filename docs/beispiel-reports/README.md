# Beispiel-Reports (fiktiv)

Zum Ausprobieren des Report-Imports mit der Seed-Kampagne „Herbstkampagne Hund“
(Performance → Report importieren). Alle Daten sind erfunden.

| Datei | Zeigt |
| --- | --- |
| `agentur-kw44-45.xlsx` | Breites Format (eine Spalte pro KPI) mit Titelzeile, KW-Spalte und Summenzeile. Die Plattform-Namen „Meta Ads“ und „CTV“ müssen beim ersten Import Kanälen zugeordnet werden (z. B. Social Reach (Paid) und CTV-Spot); danach wird das Format für die Quelle wiedererkannt. |
| `inhouse-export.csv` | Langes Format (Spalten KPI + Wert), Semikolon, Windows-1252, deutsche Zahlen. |
| `fehlerhaft.csv` | Zeigt die Fehlermeldungen (ungültige Zahl, ungültiges Datum). |
