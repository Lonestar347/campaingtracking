# Sample reports (fictional)

For trying out the report import with the seed campaign “Autumn Campaign Dog”
(Performance → Import report). All data is made up.

| File | Shows |
| --- | --- |
| `agency-wk44-45.xlsx` | Wide layout (one column per KPI) with a title row, a week column and a total row. The platform names “Meta Ads” and “CTV” have to be mapped to channels on the first import (e.g. Social Reach (Paid) and CTV spot); afterwards the format is recognised for the source. |
| `inhouse-export.csv` | Long layout (KPI + value columns), comma-separated, English numbers, DD/MM/YYYY dates. |
| `german-export.csv` | The same values as a German Excel export (semicolon, Windows-1252, `12.400` / `84,5`, `02.11.2026`) – choose “German” as number format. |
| `creatives-report.csv` | Values per creative (column “Creative”). “POS shelf wobbler” exists in the seed and gets the values; the two other creatives are created by the import. Results appear in the Creatives tab and in “Top creatives” on the dashboard. |
| `broken.csv` | Shows the error messages (invalid number, invalid date). |
